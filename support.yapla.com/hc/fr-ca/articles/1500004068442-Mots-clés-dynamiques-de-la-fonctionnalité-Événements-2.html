Mots-clés dynamiques de la fonctionnalité Événements

Les mots-clés dynamiques peuvent être utilisés pour personnaliser vos communications ainsi que vos documents.

En plus de la liste ci-dessous, vous retrouverez dans la liste des mots-clés les champs personnalisés que vous aurez ajoutés dans vos formulaires.

 

Mots-clés reliés aux détails de l'événement

Nom du mot-clé Description
Événement - Catégorie Indique la ou les catégories associés à l'événement. Voir Catégories et mots-clés.
Événement - Code Code de l'événement, tel qu'inscrit dans vos configurations avancées, voir Créer et configurer un événement
Événement - Code d'invitation Si l'événement utilise un code d'invitation, ce mot-clé permet d'ajouter le code d'invitation à la communication. Voir Configuration du processus d'inscription.
Événement - Code postal Affiche le code postal du lieu de l'événement.
Événement - Date de début de l'événement Affiche la date de début de l'événement.
Événement - Date de fin de l'événement Affiche la date de fin de l'événement.
Événement - Date de l'inscription Affiche la date à laquelle s'est inscrit le participant.
Événement - Date du jour Affiche la date du jour de l'envoie de la communication.
Événement - Description Affiche la description dans la configuration de l'événement.
Événement - Description courte Affiche la courte description dans la configuration de l'événement.
Événement - Durée en heures Affiche la durée en heure.
Événement - Email du contact Affiche le courriel du contact de l'événement renseigné dans la configuration de l'événement.
Événement - Emplacement de l'événement Affiche l'emplacement indiqué dans la configuration de l'événement.
Événement - État Affiche la province ou l'état configuré dans la section lieu de la configuration de l'événement.
Événement - Heure de début de l'événement Affiche l'heure à laquelle commence l'événement selon la configuration de l'événement.
Événement - Heure de fin de l'événement Affiche l'heure à laquelle fini l'événement selon la configuration de l'événement.
Événement - Identifiant Affiche le numéro d'identifiant incrémental de l'événement généré automatiquement.
Événement - Image de l'événement Image importé lors de la création de l'événement
Événement - Intervenants Affiche la section intervenants de la configuration de l'événement.
Événement - Libellé de durée (affiché à la place des dates) Affiche les informations du champ Libellé de durée (affiché à la place des dates) indiquées dans la description avancées de l'événement.
Événement - Liste des tarifs Ne fonctionne pas
Événement - Nom de l'événement Affiche le nom que vous avez donné à votre événement dans la configuration de l'événement.
Événement - Nom du contact Affiche le nom du contact de l'événement selon la section Organisateur de la configuration de l'événement.
Événement - Nom du forfait Affiche le tarif sélectionné par le participant.
Événement - Numéro de rue Affiche le numéro de rue configuré dans la section lieu de la configuration de l'événement.
Événement - Pays Affiche le pays configuré dans la section lieu de la configuration de l'événement.
Événement - Rue Affiche la rue configuré dans la section lieu de la configuration de l'événement.
Événement - Suite Affiche l'appartement indiqué dans la section lieu de la configuration de l'événement.
Événement - Sur invitation Affiche 1 ou 0 selon que l'événement soit sur invitation ou non.
Événement - Téléphone du contact Affiche le numéro de téléphone du contact de l'événement selon la section Organisateur de la configuration de l'événement.
Événement - Vignette Affiche l'image de la vignette de l'événement selon la configuration de l'événement.
Événement - Ville Affiche la ville où aura lieu l'événement selon la section lieu de la configuration de l'événement.

 

Mots-clés reliés à la facture du participant ou responsable

Nom du mot-clé Description
Facture - Adresse Affiche l'adresse sur la facture.
Facture - Code postal Affiche le code postal sur la facture.
Facture - Courriel Affiche le courriel sur la facture.
Facture - Date du paiement Affiche la date du paiement sur la facture.
Facture - Date du paiement (avec heure) Affiche la date du paiement en incluant l'heure de création de la facture.
Facture - Liste des numéros de taxe Affiche la liste des numéros de taxe pour les taxes appliquées à la facture.
Facture - Mode de paiement Affiche le mode de paiement utilisé pour régler la facture.
Facture - Montant total Affiche le montant total de la facture.
Facture - Nom Affiche le nom indiqué sur la facture.
Facture - Nombre d'inscriptions Affiche le nombre d'inscriptions sur la même facture.
Facture - Numéro de chèque Affiche le numéro du chèque utilisé pour le paiement de la facture.
Facture - N° de facture Affiche le numéro de la facture.
Facture - Organisation Affiche le nom de l'organisation sur la facture.
Facture - Pays Affiche le pays indiqué sur la facture.
Facture - Prénom Affiche le prénom indiqué sur la facture.
Facture - Province Affiche la province indiqué sur la facture.
Facture - Sous-total (montant avant taxes) Indique la montant total avant taxe de la facture.
Facture - Tableau pour facturation Ce mot clé va recréer le tableau de facturation utilisé pour la facturation dans la communication, voir Afficher les informations de facturation dans une communication automatique.
Facture - TPS Indique le montant de TPS de la facture.
Facture - TVQ Indique le montant de TVQ de la facture.
Facture - Ville Affiche la ville indiquée sur la facture.

 

Mot-clés reliés à l'inscription

Nom du mot-clé Description
Inscriptions - Adresse Affiche l'adresse inscrite dans le champ natif adresse pour le participant.
Inscriptions - Code barre Affiche le code barre relié au code d'inscription du participant
Inscriptions - Code identifiant Affiche le code identifiant du participant
Inscriptions - Code postal Affiche le code postal inscrit dans le champ natif code postal pour le participant.
Inscriptions - Courriel Affiche le courriel inscrit dans le champ natif courriel pour le participant.
Inscriptions - Date Si utilisé dans le formulaire, affiche la date du champ natif Date remplit par le participant.
Inscriptions - Évaluation Affiche le texte du champ natif Évaluation remplit par le participant.
Inscriptions - Heure d'arrivée Affiche l'heure d'arrivée inscrite dans le champ natif heure d'arrivée.
Inscriptions - Langue Affiche la langue inscrite dans le champ natif langue pour le participant.
Inscriptions - Nom Affiche le nom inscrit dans le champ natif nom pour le participant.
Inscriptions - Notes Affiche le texte du champ natif Notes remplit par le participant.
Inscriptions - Numéro de membre Affiche le numéro de membre du participant.
Inscriptions - N° du groupe Affiche le N° du groupe du participant, si il a acheté un tarif de groupe
Inscriptions - Pays Affiche le pays inscrit dans le champ natif pays pour le participant.
Inscriptions - Prénom Affiche le prénom inscrit dans le champ natif prénom pour le participant.
Inscriptions - Présent Présence du participant (Oui ou non)
Inscriptions - Province Affiche la province inscrite dans le champ natif province pour le participant.
Inscriptions - QR Code Affiche le code QR lié à l'inscription du participant.
Inscriptions - Statut Affiche le statut de l'inscription du participant.
Inscriptions - Téléphone Affiche le numéro inscrit dans le champ natif téléphone pour le participant.
Inscriptions - Titre Affiche le titre inscrit dans le champ natif titre pour le participant.
Inscriptions - Ville Affiche la ville inscrite dans le champ natif ville pour le participant.

 

Mot-clés reliés au responsable de l'inscription

Pour plus d'informations sur le responsable d'inscription, consulter Fonctionnement du mode responsable d'inscription d'un événement.

Nom du mot-clé Description
Responsable - Adresse Affiche l'adresse du champ natif Adresse remplit par le responsable d'inscription.
Responsable - Adresse postale Affiche l'adresse postale complète du responsable d'inscription en regroupant l'information des champs natifs Adresse, Ville, Province, Pays, Code postal.
Responsable - Code postal Affiche le code postal du champ natif Code postal remplit par le responsable d'inscription.
Responsable - Courriel Affiche le courriel du champ natif courriel remplit par le responsable d'inscription.
Responsable - Date Affiche la date du champ natif date remplit par le responsable d'inscription.
Responsable - Évaluation Affiche l'évaluation du champ natif Évaluation remplit par le responsable d'inscription.
Responsable - Langue Affiche la langue du champ natif Langue remplit par le responsable d'inscription.
Responsable - Liste des participants Affiche la liste des participants inscrits par le responsable d'inscription.
Responsable - Nom Affiche le nom du champ natif nom remplit par le responsable d'inscription.
Responsable - Nom de l'organisation Affiche le nom de l'organisation du responsable d'inscription.
Responsable - Notes Affiche le texte du champ natif Notes remplit par le responsable d'inscription.
Responsable - Pays Affiche le pays inscrit dans le champ natif pays pour le responsable d'inscription.
Responsable - Prénom Affiche le prénom inscrit dans le champ natif prénom pour le responsable d'inscription.
Responsable - Province Affiche la province inscrite dans le champ natif province pour le responsable d'inscription.
Responsable - Téléphone Affiche le numéro inscrit dans le champ natif téléphone pour le responsable d'inscription.
Responsable - Titre Affiche le titre inscrit dans le champ natif titre pour le responsable d'inscription.
Responsable - Ville Affiche la ville inscrite dans le champ natif ville pour le responsable d'inscription.
