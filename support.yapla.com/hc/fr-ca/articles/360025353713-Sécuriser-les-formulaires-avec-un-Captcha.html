Sécuriser les formulaires avec un Captcha

Avant d’activer la fonction sur vos formulaires, vous devez vous ouvrir un compte gratuit et créer vos clés de sécurité, qui seront uniques à votre site.

Pour créer des clés de sécurité :

  1. Rendez-vous sur le site de Google reCAPTCHA
  2. Connectez-vous avec un compte Google (ceci vous permettra de gérer vos configurations par la suite)
  3. Dans le champ “Libellé” entrez le nom de votre site
  4. Dans la zone “Type de reCAPTCHA” cochez la case Défi.
  5. Puis cochez la badge Badge reCAPTCHA invisible.
  6. Entrez l’adresse (url) de votre site (Si vous avez plusieurs sites, vous pouvez les inscrire ici.  La clé qui vous sera attribuée à la prochaine étape pourra être utilisée pour tous vos sites)
  7. Acceptez les conditions d’utilisation et cliquez sur Enregistrer

Sur la page suivante, les seules informations dont vous aurez besoin sont les 2 clés.

Ajout dans Yapla

  1. Dans Yapla, ouvrez votre site dans l’application Sites web et cliquez sur le sous-menu Outils
  2. Dans la section reCAPTCHA, inscrivez la clé du site et la clé secrète dans les sections correspondantes.
  3. Une fois que les clés sont entrées, vous pourrez activer le reCAPTCHA dans un ou plusieurs formulaires en cochant la case dans les configurations du module.


Par défaut, la sécurité du reCAPTCHA est au plus bas. Si vous recevez encore beaucoup de spam, connectez-vous au site de reCAPTCHA et modifiez les paramètres pour que la sécurité soit plus élevée.
