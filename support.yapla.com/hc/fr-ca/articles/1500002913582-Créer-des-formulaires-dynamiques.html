Créer des formulaires dynamiques

Il est possible de rendre vos formulaires dynamiques pour obtenir plus de flexibilité dans vos questions. Affichez ou non des champs ou des sections conditionnels en fonction des réponses fournies. 

Dans cet article:

  • Afficher des champs supplémentaires en fonction de la réponse
  • Afficher des sections en fonction d'une réponse donnée
  • Questions fréquentes

Afficher des champs supplémentaires en fonction de la réponse

Les champs conditionnels permettent d’afficher des questions additionnelles directement sous une question donnée lorsque certaines réponses sont sélectionnées dans votre formulaire. Cette option est disponible pour les champs suivant :

  • Case à cocher
  • Cases à cocher multiples
  • Liste de sélection
  • Réponse à choix unique (radio)

L'affichage de champs conditionnels est utile lorsque vous souhaitez obtenir plus de détails concernant un choix de réponse. Afin d’ajouter un champ conditionnel dans votre formulaire, vous devrez d’abord créer tous les champs dont vous aurez besoin.

Comment les configurer dans les formulaires

Si vous ajoutez une condition dans une section contenant 2 colonnes, vos champs se placeront automatiquement dans une seule colonne. Ceci permet d’éviter un décalage de la 2e colonne lors de l’apparition des champs additionnels.

Ajoutez le champ avec le choix de réponse à l’endroit désiré dans votre formulaire. Cliquez ensuite sur les trois petits points à droite du champ et sélectionnez le sous-menu Conditions.

Choisissez ensuite les règles d’affichage, c'est-à-dire le ou les choix de réponse qui feront afficher les champs de questions conditionnels. Vous pouvez également à cet endroit ajouter un texte descriptif qui apparaîtra avant les champs conditionnels.

Une fois l'option de champs conditionnels créée sous la question, vous pouvez y ajouter un ou plusieurs champs.

Fonctionnement en mode édition

Sur votre site web, ainsi que dans vos formulaires sur Yapla, les champs conditionnels n’apparaîtront que si les options mentionnées sont sélectionnées. De plus, si les champs additionnels sont obligatoires, ils devront être remplis seulement s'ils sont visibles.

Fonctionnement en mode visualisation

En mode visualisation, les champs supplémentaires ne s’afficheront que si la condition s’applique.

Pour aller plus loin, vous pouvez également ajouter plus d'une condition à vos questions en fonction de la réponse donnée. Par exemple, chaque réponse fournie peut déclencher une condition différente. Il suffit de sélectionner les trois points à droite de votre question et d'y ajouter une condition de nouveau. Cette option n'est disponible que si vous avez configuré une question à choix multiples.

Dans l'exemple suivant, si une marque ou l'autre est sélectionnée, les modèles correspondants s'afficheront.

Afficher des sections en fonction d'une réponse donnée

Les sections additionnelles permettent également d'afficher un ou plusieurs champs additionnels, mais dans une section supplémentaire qui s'affichera en fonction d'une réponse donnée. Cette option est disponible pour les champs suivants :

  • Case à cocher
  • Liste de sélection
  • Boutons radio
  • Réponse à choix multiples

Cette option est utile si vous souhaitez construire une section dédiée à une réponse fournie, mais dans une section isolée.

Comment les configurer dans les formulaires

Pour ajouter une section qui s'affichera en condition d'une réponse fournie à l'une de vos questions configurées, cliquez sur Ajouter une section et donnez-lui un nom. Cliquez sur la roue , cochez Afficher cette section en fonction d'une réponse donnée puis sélectionnez la question concernée sous Champ permettant l'affichage. Sous Valeur affichant la section, sélectionnez tous les choix qui permettront l'affichage de cette section. Ajoutez ensuite tous les champs de question souhaités dans cette nouvelle section puis enregistrez.

Dans cet exemple, lorsqu'un choix de niveau d'étude est fait parmi DES, BAC, Maitrise ou PhD, une section additionnelle s'affichera dans le formulaire pour permettre d'ajouter une question relative à l'établissement de formation. La section additionnelle s'affichera comme suit :


Si la réponse est "Aucun", aucune section additionnelle ne s'affichera.

En mode édition, des étiquettes ( ou ) vous permettent de retrouver facilement les conditions appliquées à une section ou si une section ne s'adresse qu'aux administrateurs.

Questions fréquentes

Les champs et sections conditionnels affecteront-ils mes exports de données ?

Il n’y aura pas de changement dans vos exports. Les questions seront séparées dans des colonnes distinctes, comme pour les autres champs.

Mon formulaire est déjà en ligne, puis-je quand même ajouter un champ conditionnel ?

Les formulaires peuvent être modifiés en tout temps, y compris après leur mise en ligne.
