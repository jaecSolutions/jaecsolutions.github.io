Optimiser son site pour les moteurs de recherche (SEO)

Le SEO (optimisation pour les moteurs de recherche) a pour objectif d’améliorer la visibilité de votre site web dans les résultats de recherche, afin d’attirer davantage de visiteurs qualifiés et d’augmenter ainsi vos chances de conversion ou d’engagement.

L’optimisation s’applique à trois niveaux : le site, ses pages, et ses articles.

Dans cet article :

  • SEO du site
  • SEO des pages
  • SEO des articles

SEO du site

Optimiser les donnée de votre site renforce la confiance des moteurs de recherche et améliore son positionnement global. Rendez-vous dans Sites web > [site web] > SEO

Détails des champs présents

  • Suffixe - Titre : Ajouté à tous les titres de page. Utilisez un séparateur (- ou |).
  • Mots-clés : Jusqu’à 60 caractères.
  • Sitemap : Fichier XML listant les pages importantes. Aide les moteurs à explorer votre site. En savoir plus.
  • Robots.txt : Fichier indiquant aux robots quelles pages explorer. En savoir plus.
  • Image : Utilisée lors du partage du site.
  • Description : 165 caractères maximum. Résume votre organisation. Utilisez un vocabulaire lié à votre domaine pour faciliter l’indexation.
  • Indexation - Cochez « Ne pas indexer ce site » si vous souhaitez le rendre invisible aux moteurs de recherche.
  • Données structurées - Le fil d’Ariane, affiché sur toutes les pages, aide Google et vos visiteurs à comprendre la structure du site. Il est intégré via des balises dans le code HTML.

SEO des pages

Les balises (titre, méta-description, H1-H6) et l’optimisation des médias (images, vidéos) influencent directement la manière dont la page est indexée et classée. Rendez-vous dans Sites web > [votre site web] > Pages > [la page souhaitée] > SEO.

Détails des champs présents

  • Page - balise title : 60 caractères max. S’affiche dans les onglets et résultats de recherche.
  • Description : Résumé de 165 caractères. Préférez une description unique.
  • Lien canonique : À utiliser si l’URL réelle diffère de celle souhaitée pour l’indexation.
  • Choisissez des mots-clés spécifiques à chaque page.

SEO des articles

Un contenu riche, original et bien structuré avec des mots-clés pertinents augmente la pertinence de vos pages d'articles aux yeux des moteurs de recherche. Rendez-vous dans Site Web > Articles > [l'article souhaitée] sous la section Optimisation pour les moteurs de recherche (SEO).

Détails des champs présents

  • Article - Titre (balise title) - Ce titre s’affichera dans les résultats de recherche. Ajoutez les mots-clés importants liés à votre article.
  • Identifiant pour adresse URL - Permet d'identifier l'article dans l'URL de la page. Cet identifiant doit rester simple et compréhensible pour les utilisateurs et les moteurs de recherche. Modifier l'identifiant une fois l'article publié risque d'occasionner du contenu dupliqué pour les moteurs de recherche.
  • Description - Elle décrit brièvement le contenu de l’article pour les moteurs de recherche. Soyez clair, précis et incluez des mots-clés pertinents.
  • Image - Pour publication sur les réseau sociaux
  • Lien canonique - Indiquer l'URL de la page sous laquelle un moteur de recherche doit indexer cette page. Le lien canonique indique aux moteurs de recherche quelle est la version principale d’un contenu lorsqu’il existe plusieurs URL similaires.
  • Mots-clés - Ce sont les termes importants qui décrivent votre article. Utilisez des mots simples et courants que votre public est susceptible de rechercher.

Questions fréquentes

Pourquoi mon site n’apparaît-il pas sur Google ?

Plusieurs raisons peuvent expliquer l'absence de votre site dans les résultats de recherche, mais la principale est qu’il n’a pas encore été découvert par les moteurs. Pour y remédier :

  • Vérifiez que l’option « Ne pas indexer ce site » est décochée dans les paramètres SEO.
  • Assurez-vous que la page d’accueil n’est pas définie comme page d’erreur 404.
  • Partagez votre site sur les réseaux sociaux pour générer des liens entrants.
  • Soyez patient : le référencement peut prendre plusieurs jours, surtout pour un nouveau site. Installez des outils comme Google Analytics ou Search Console. Avec du trafic et un bon contenu, il gagnera en visibilité.
  • Si vous êtes une association, explorez Google Ad Grants pour bénéficier d’un budget publicitaire gratuit.
