Ajouter le module connexion dans l'entête d'un site web

Le module Connexion de la fonctionnlité Site Web permet aux membres et/ou contacts de votre organisation de se connecter sur votre site web. Vous pouvez configurer la page contenant le module afin qu'elle s'affiche dans l'entête de votre site.

Afficher le bouton connexion dans l'entête du site web

Vous pouvez décider d'afficher la page connexion dans l'entête plutôt que dans le menu de votre site web.

D'abord, pour retirer la page du menu, choisissez votre page contenant le module de connexion puis le sous-menu Configuration. Dans la section Accès, cocher l'option "Ne pas afficher cette page dans le menu de votre site web". Cliquez sur 

Ensuite, dans les pages maîtresses de votre site, éditez les configurations du module Entête puis activez la Section Connexion.

Choisissez la page contenant votre module Connexion et choisissez d'afficher les différentes options disponibles:

Les liens "Renouveller mon adhésion" et "Devenir Membre" peuvent s'afficher dans l'entête de votre web. Il est également possible de choisir d'afficher le nom du membre une fois qu'il est connecté.

Une fois les configurations de la section Connexion réalisées, cliquez sur Enregistrer.

Une fois votre module Connexion configuré, vos membres peuvent se connecter directement à partir de votre site et accéder à leur Espace Membre ou encore aux pages réservées aux membres connectés.
