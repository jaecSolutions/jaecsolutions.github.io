Promouvoir vos produits

Il est possible avec Yapla de mettre en marché des produits via la fonctionnalité Données. Une fois, la configuration de vos objets réalisés, il est possible de créer des articles pour promouvoir ceux-ci. Ces articles de promotion en mode Mosaique vous permettront d'afficher plusieurs produits sur la même page.

Créer les articles de promotion

Créer la catégorie d'articles

Tout d'abord, vous devrez créer une catégorie pour vos articles. Dans les paramètres de la fonctionnalité Site web, choisissez la tuile Catégories.

Créez un nouvelle catégorie qui contiendra tous vos articles de produits. 

Créer les articles

Pour chacun de vos produits, créez un article dans la fonctionnalité Site Web. Sélectionnez la bonne catégorie et introduisez votre produit à l'aide d'un court texte.

Ajouter un bouton de commande dans votre article

Sélectionnez le mot Commandez dans votre texte et cliquez sur l'icone de lien.

Inscrivez l'url de la page contenant le formulaire Données de votre produit dans le champ URL.

Dans les fonctions avancées, ajoutez une classe de style < btn btn-primary > pour donner l'allure d'un bouton à votre mot.

Enregistrez votre article.

Intégrer les articles au site web

Sur votre site web, sélectionnez votre page où vous souhaitez faire la promotion de vos articles. Par la suite, sélectionnez une zone et ajoutez le module Articles en vedettes. Configurez le module selon vos préférences et choisissez la catégorie contenant vos articles de produits. 

Et voilà! Vos articles sont maintenant plublier et vos utilisateurs pourront faire l'achat de vos produits via le bouton Commandez.

Ajouter les formulaires d'achat au site web 

Une fois, la configuration de vos objets réalisés, vous devez les publier sur votre site web afin de débuter la vente de ceux-ci. 

Mettre en marché un produit

Il n'existe pas de boutique complète dans Yapla. Toutefois, plusieurs alternatives sont possibles. L'une d'elle s'effectue via la fonctionnalité Données. Vous pouvez créer des objets avec paiement à l'aide de formulaires contenant des tarifs.
