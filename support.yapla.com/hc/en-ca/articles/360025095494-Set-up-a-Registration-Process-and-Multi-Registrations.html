Set up a Registration Process and Multi-Registrations

Depending on your needs, several options are available to simplify or refine the registration form for your events by modifying the registration process or adding multi-registration configurations to your events.

In this article:

  • Set up a Registration Process
  • Set up Multi-Registrations

Set up a Registration Process

To configure an event's registration process, select the event and choose the Configuration menu. The options can be found in the Process submenu.

List of Fields

  • Allow online registrations - If you want to display an event without allowing visitors to register, for example, if registrations are managed through another website, you can uncheck this option, and the Register button will no longer appear.
  • Allow the same email to subscribe several times - limit one registration per email address by unchecking this option.
  • Allow the download of the event in the calendar - Allows participants to add the event to their Outlook or Gmail calendar, for example.
  • Allow the member to modify his registration in his connected space - If the participant is a member, they will be able to log in to their member space to modify their event registration.

Identification and Recruitment

  • Activate the identification step - Allows members to log in with their Yapla account to benefit from preferential rates. These boxes allow you to define whether your event is limited to your members or not.
    • Suggest becoming a member - Adds a button linking to the Become a Member form.
    • Allow to find an organization in order to become a delegate member automatically - If your organization manages multiple members, this function allows employees to register as members, even if they do not yet have an account in Yapla.
    • Allow to register without logging in - Allows participants to continue the registration without logging in. If you want to limit registration for this event to your members only, leave this box blank.

Managing Available Seats

  • Limit the number of available seats - Allows setting the maximum number of available seats. Once this number is reached, it will no longer be possible to register for the event.

Registration Manager

  • Enable registration manager mode - Allows a manager to complete the registration without participating in the event.

Invitation-Only Event

  • Registration limited to holders of an invitation only - Allows creating an access code that participants must enter.

Set up Multi-Registrationss

To configure multiple registrations, go to the multi-registration sub-tab.

  • Enable registration of multiple participants for the same transaction - This option enables the registration of multiple participants at once.
    • No subscription form for additional participants - Only the number of additional participants needs to be specified.
    • Identical subscription form for all participants - The same form must be completed for each participant.
    • Simplified subscription form for additional participants - Additional participants will have a different form with fewer or different fields.
  • Participant Registration Help System
    • Suggest the list of members from the organization of the registration manager - A box is added in the registration process. When the account has organizations and the representative is logged in, they can choose from the organization’s members to pre-fill the form.
    • Suggest the list of all the contacts in the organization of the registration manager - A box is added in the registration process. When the account has organizations and the representative is logged in, they can choose from the organization’s contacts to pre-fill the form.
  • Automatic creation of delegate members in an organization - If you wish to automatically create delegated members in an organization during registration, select the desired procedure.
  • Rates offered to a logged-in member for additional participants
    • Offer the same rates as the member registering: All additional participants will have the same rate. You can set a limit for additional registrations. The registering member is included in the total allowed registrations.
    • Offer only certain rates for additional participants: Select which prices will be available for additional participants.

      Configure the rates the same way for additional participants registered by a representative or delegate.
