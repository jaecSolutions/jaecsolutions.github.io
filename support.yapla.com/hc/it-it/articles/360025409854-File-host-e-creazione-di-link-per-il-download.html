File host e creazione di link per il download

L'editor html della funzionalità Sito web ti consente di aggiungere facilmente un link per il download a una scheda. I tipi di scheda accettati sono: png, jpg, gif, zip, rar, txt, doc, docx, xls, xlsx, pdf e la dimensione massima per un'immagine è 2 MB e 5 MB per una scheda.

Aggiungi un link a una scheda nella tua area personalizzata

  1. Nel modulo "Contenuto personalizzato», seleziona la posizione (area di testo o immagine) in cui desideri inserire il link e clicca sull'icona del link nell'editor.
  2. Compila il campo «Testo visualizzato» con il testo che desideri visualizzare nella tua zona.
  3. Quindi clicca su «naviga nel server» per caricare una scheda o utilizzare un file che hai già caricato in precedenza.

Carica una nuova scheda

Per caricare un nuovo file, clicca sul pulsante «naviga nel server», scegli la sottocartella, clicca su Carica e seleziona il file sul tuo computer. Affinché il file venga visualizzato senza problemi su tutti i browser, è preferibile assegnare un nome al file senza spazi o caratteri speciali.



Fai doppio clic sulla scheda desiderata per selezionarla.

Modifica il target del link

Affinché il tuo link si apra in una nuova scheda, ricordati di cambiare il target del link accedendo alla scheda «Target».
Seleziona l'opzione «Nuova finestra (_blank)» e clicca su OK.



Salva le modifiche e vai a vedere il risultato sul tuo sito web.
