Créer des campagnes d'adhésions simplifiées

Qu'est-ce que les campagnes simplifiées?

Le principal avantage du mode simplifié est la possibilité de passer outre le système de renouvellement et de création d’espace membre sur Yapla. 

Il permet d’automatiser un certain nombre de tâches à partir du forfait Essentiel (par exemple la comptabilité) tout en limitant le temps d’investissement nécessaire à la mise en place d’un système d'inscription et paiement en ligne.

L’intégration d’une campagne simplifiée sur un site Yapla n’est pas possible via des modules du site web. Il faut passer par la monopage.

Pour qui sont-elles utiles ?

  • Première expérience dans l’inscription et le paiement en ligne, l’association passe d’un système papier / traditionnel à un système numérisé et automatisé 
  • Associations sportives 
  • Petites associations 
  • Besoin urgent de lancer une campagne d’inscription
  • Je gère des personnes physiques, qui n’ont pas forcément de courriel. Mon objectif est de récupérer de l’information et/ou des paiements. Je n’ai pas besoin d’espace membre ni de zones réservées. 

Limitations par rapport aux campagnes de la base de membres:

  • Comme le membre ne se crée pas d’espace avec les campagnes d'adhésion simplifiée, ce dernier ne peut avoir un tarif préférentiel pour vos événements
  • Il n'y a pas de base de données de vos membres, mais vous avez accès à la liste des adhérents de chaque campagne.
  • Les options de renouvellement ne sont pas disponibles
  • Les processus de validation des adhésions ne sont pas disponibles
  • Les communications automatiques ne sont pas personnalisables
  • Vous ne pouvez pas y joindre des documents personnalisés
  • L'Espace membre sur votre site web Yapla n'est pas disponible
  • L'option d'import des membres n'est pas disponible

Activer les campagnes simplifiées

Par défaut, les campagnes d'adhésions simplifiées sont désactivées. Rendez-vous dans Configurations > Fonctionnalités puis sélectionnez Configurer à droite de Membres. Activez l'option des campagnes simplifiées. Toutes les campagnes créées après l'activation de cette option seront créées sous le format simplifié.

Si vous aviez déjà activé une campagne avant d'avoir activé l'option des campagnes simplifiées, il ne sera pas possible de la convertir. Il faudra recommencer.

Étape 1 : Créer une campagne d'adhésions simplifiée

Une fois connecté à votre compte Yapla, cliquez sur Membres dans le menu de gauche, puis sur Créer une campagne d’adhésion.

Vous devrez ensuite renseigner les informations suivantes :

  • Nom : Le nom de votre campagne d'adhésion, tel qu’il apparaîtra à vos adhérents
  • Description : La description permet d’afficher du texte supplémentaire sur votre site. Par exemple, les avantages de l’adhésion ou ce qu’elle inclut.
  • Période d’inscription : Les dates de début et de fin de la période d’inscription. Il ne sera pas possible de s’inscrire avant ou après cette période. À noter : bien que la date de début est obligatoire (et peut être dans le passé), la date de fin peut être laissée vide si vous ne souhaitez pas fermer les inscriptions à cette campagne. Aussi, ces dates peuvent être changées en tout temps, y compris après le lancement des inscriptions.

Après avoir renseigné les informations, cliquez sur Suivant.

Étape 2 : Personnaliser le formulaire

Vous pourrez personnaliser le formulaire que vos membres devront remplir en y ajoutant toutes les informations dont vous aurez besoin.

Une fois votre formulaire adapté selon vos besoins, vous devrez créer la ou les adhésions proposées à vos adhérents. Vous pouvez créer un seul type d’adhésion si tous vos membres ont le même tarif et les mêmes avantages. Créez plusieurs types si vous offrez des tarifs ou groupes différents. Si plusieurs types d’adhésions sont disponibles, les adhérents pourront choisir lors de leur inscription.

Étape 3 : Diffuser votre campagne

Votre campagne est en ligne, vous pouvez dès à présent voir votre page, la modifier si vous le souhaitez et la diffuser à votre réseau !

Lorsque vous cliquez sur Modifier sous l’aperçu de la page, vous accédez à une page permettant de personnaliser :

  • Le logo de votre association affiché sur cette page
  • Les couleurs de la page
  • La police utilisée

Une fois votre campagne créée, cette dernière pourra être modifiée en tout temps via le sous-menu Campagnes de la fonctionnalité Membres.

Communications disponibles

Trois types de communications seront envoyées automatiquement via Yapla :

  1. Adhésion en attente de paiement (Forfaits Essentiel et supérieurs). Sera envoyée après l’inscription, si le mode de paiement sélectionné est Chèque ou Virement.
  2. Adhésion validée. Sera envoyée automatiquement à la fin de l’inscription. Si l’adhésion est en attente de paiement, elle sera envoyée après le paiement.
  3. Adhésion annulée. Sera envoyée uniquement si l’adhésion est annulée par un administrateur dans Yapla. 

Yapla Newsletters

N'oubliez pas, la fonctionnalité Yapla Newsletter est votre meilleur allié lorsqu'il s'agit de communiquer auprès de votre communauté. Envoyez une infolettre spéciale pour diffuser le lancement de votre campagne d'adhésion en y incluant un bouton vers votre page d'adhésion. Visionner notre webinaire pour apprendre à configurer vos newsletters.

Désactiver les campagnes simplifiées

Vous pouvez désactiver l'option campagnes simplifiées dans Configuration > Fonctionnalité > Membres > Configurer. Vous devrez supprimer toutes vos campagnes simplifiées afin de désactiver l'option.
