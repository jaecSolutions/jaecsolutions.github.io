Rembourser une inscription d'événement dans Yapla

Yapla vous permet de rembourser automatiquement des transactions effectuées lorsqu'il s'agit d'un paiement en ligne (Carte Bancaire).

Rembourser automatiquement une transaction dans Événements

Attention : Vous ne pourrez effectuer un remboursement automatique que si votre compte Yapla possède les fonds suffisants pour rembourser la transaction. 

Pour effectuer un remboursement d'une inscription, vous devez vous rendre sur l'inscription que vous souhaitez rembourser : 

Puis cliquer sur le bouton "Annuler l'inscription" en le sélectionnant depuis "Actions disponibles" : 

 

Configurer les frais d'annulation (forfait Plus et Premium)

Yapla vous propose, lorsque vous en mode commission, d'appliquer des frais d'annulation lors du remboursement d'une transaction afin de couvrir la commission appliquée à cette transaction. 

Vous pouvez configurer ces frais d'annulation dans le Tarif de l’évènement : 

Vous avez la possibilité d'indiquer le montant des frais d'annulation par transaction en % ou en € pour chaque inscription. 

Vous devez ensuite sélectionner le compte de revenus qui sera impacté comptablement. Comme pour les autres applications, nous vous conseillons d'appliquer le compte 791000 - Transfert de charges d'exploitation.

Par la suite, vous serez en mesure d'ajuster manuellement les frais lors de chaque annulation.
