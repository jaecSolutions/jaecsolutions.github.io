Guide | Créer et configurer un événement

Créer un événement est un bon moyen de mobiliser votre communauté. Yapla vous permet de créer facilement un événement, puis de le promouvoir sur vos réseaux sociaux et votre site. Et pour vous faire gagner du temps, il regorge d’outils pour vous aider à automatiser la gestion de votre événement.

Dans cet article :

  • Créer son événement
  • Fixer ses tarifs
  • Créer un formulaire d'inscription
  • Créer une page web pour son événement
  • Configurer les communications
  • Promouvoir l'événement
  • Configurations de l'événement
  • FAQ

Créer son événement

Rendez-vous dans Événements > Événements puis cliquez sur Ajouter un événement, en bas à droite de l’écran.

1. Entrez les informations relatives à votre événement :

  • Nom de l’événement.
  • Date et heure de début : vous pouvez également ajouter une date de fin de l’événement.
  • Image.
  • Description pour les réseaux sociaux : ce texte court pourra être partagé par vos participants sur leurs réseaux sociaux, pour attirer un public plus large. Si vous n’inscrivez rien dans cette case, le titre de l’événement s’affichera avec le lien de partage.
  • Description : ce texte sera affiché sur la page de votre événement.

Une fois ces champs renseignés, cliquez sur Suivant.

2. Remplissez les champs relatifs au lieu et à l’adresse de l’événement.

  • Nom du lieu de l’événement - il faudra ensuite en indiquer l’adresse exacte dans le champ suivant.
  • Adresse de l’événement - s'il s'agit d'un événement en ligne, cliquez sur Événement en ligne sous le champ Adresse.
    • Dans le cas d'un lieu physique, saisissez l’adresse complète. Si celle-ci est listée dans Google, vous pouvez choisir de la générer automatiquement à l’aide de Google Maps.

3. Définir l’organisateur de l’événement.

Pour que les participants puissent vous joindre, affichez les informations de l’organisateur sur la page dédiée à l’événement. Et si vous organisez votre événement avec un partenaire externe, vous pourrez également l’indiquer à cette étape. Il sera ainsi en copie de certaines communications automatiques.

Inscrivez le nom de l’organisateur. Par défaut, c’est votre nom d’administrateur, mais il est possible d’y inscrire un nom différent. Vous pouvez également ajouter le numéro de téléphone et le courriel de l’organisateur.

Cliquez sur Suivant.

Fixer ses tarifs

Par défaut, l’événement est gratuit. Vous pouvez cependant ajouter un ou plusieurs tarifs pour les inscriptions, en cliquant sur Ajouter un tarif. Pour découvrir comment configurer des tarifs avec Yapla, consultez notre article d’aide à ce sujet.

Cliquez sur Suivant.

Créer un formulaire d’inscription

Vous pouvez personnaliser le formulaire d’inscription à votre événement. Modifiez son nom, ajoutez et déplacez des champs et ajoutez des sections selon vos besoins.

Cliquez sur Suivant.

Créer une page web pour son événement

Vous pouvez générer une page unique pour votre événement et l'afficher sur votre site. Cette fonctionnalité est aussi bien disponible pour tous les usagers, qu’ils aient créé ou non leur site avec Yapla.

Choisissez le logo de votre événement, les couleurs et la police de la page. Une fois ces champs de base renseignés, la création de votre événement sera achevée. Vous pouvez maintenant visualiser la page web de votre événement.

Configurer les communications

Rendez-vous dans votre événement et sélectionnez la tuile Communications. Vous retrouverez la liste des communications disponibles et leur déclencheur. Personnalisez et configurez les communications en fonction de vos besoins. Pour en apprendre davantage sur le fonctionnement des communications, consultez cet article.

Promouvoir l’événement

À cette étape, un lien est généré pour que vous puissiez partager votre événement dans votre newsletter par exemple.
Vous pouvez aussi partager l’événement sur vos réseaux sociaux, afin que vos abonnés le partagent à leur tour.
Finalement, vous pouvez aussi copier le code d’intégration de l’événement pour ajouter sa page au site de votre association.

Sauvegardez.

Configurations de l'événement.

Pour personnaliser votre événement, ou modifier les informations précédemment enregistrées, rendez-vous dans l’option Événements de la fonctionnalité Événements. Ensuite, choisissez la tuile Configuration.

Descriptions avancées

  • la vignette (miniature pour la page avec une mosaïque de vos événements). La vignette est différente de l’image qui illustre le détail de l’événement.
  • une courte description (visible sur la page avec une mosaïque de vos événements).
  • une vidéo, en ajoutant un code Iframe.
  • des descriptions complémentaires (qui peuvent servir pour les partenaires, par exemple).
  • une durée (qui remplace la date de votre événement). Ceci peut servir lorsque votre événement est reporté à une date que vous ne connaissez pas encore. Vous pouvez par exemple y inscrire : Date à déterminer. C’est aussi une option intéressante pour les événements qui se tiennent sur une longue période, car elle permet d’en personnaliser la durée.
  • la durée en heure de votre événement, si vous en avez besoin.

Indiquer un lieu

Dans cet onglet, vous pouvez ajouter ou modifier :

  • l’adresse physique de votre événement, avec Google Maps
  • l’URL de l’événement s’il se tient en ligne

Organisateur

Dans l’onglet Organisateur, vous pouvez
  • indiquer la personne à contacter en cas de questions des participants
  • ajouter des intervenants (par exemple, des conférenciers).

Processus d'inscription

L’onglet Processus d’inscription vous permet notamment de définir si le nombre de places est limité, ou bien s’il faut être membre pour avoir accès à l’événement.

Il est aussi possible de désactiver le processus d’inscription, en décochant la case Permettre les inscriptions en ligne. Votre événement restera en ligne, mais les visiteurs n’auront pas besoin de s’y inscrire pour y assister.

Pour en savoir plus sur les options d’inscription à un événement, consultez notre article d’aide à ce sujet.  

Conditions

Dans l’onglet Conditions pour vous pouvez indiquer les procédures à suivre pour les remboursements, les annulations, et tout autre cas de figure liés à l’événement. Ces informations sont alors affichées dans le formulaire d’inscription et le participant doit confirmer son accord. Pour en savoir plus, sur les conditions, vous pouvez consulter notre article d’aide à ce sujet.

Foire aux questions

Est-ce possible de supprimer un événement si des inscriptions ont été effectuées dans celui-ci ?

Dans Yapla, il n'est pas possible de supprimer un événement qu'il y ait ou non des inscriptions dans ce dernier. Vous pouvez cependant archiver un événement en cliquant sur l'engrenage à droite de celui-ci dans la liste de vos événements, puis en sélectionnant Archiver.

Pour aller plus loin : les configurations avancées d’un événement

Maintenant que votre événement est créé et configuré, vous pouvez aussi en déterminer plusieurs spécificités. Ainsi, vous pouvez décider de fixer plusieurs types de tarifs pour accéder à l’événement ; ou bien, vous pouvez définir une période limite pour les inscriptions.
